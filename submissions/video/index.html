Watch a certificate expire

One real-time take, nothing cut: a certificate written with a 40-second lifetime goes green, then red, while the query on screen never changes and no date is ever compared. The gate check is gateCheck() imported unmodified from layak.sketch.ts — the same function the 17 invariants run — against MemArkiv, the executable spec.
