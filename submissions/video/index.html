Demo · the claim, running

Watch a certificate expire

1:01 · 1080p · h264/aac · subtitles: VTT · SRT · MP4

One real-time take, nothing cut: a certificate written with a 40-second lifetime goes green, then red, while the query on screen never changes and no date is ever compared. The gate check is gateCheck() imported unmodified from layak.sketch.ts — the same function the 17 invariants run — against MemArkiv, the executable spec. Run it yourself: demo/ (add ?ttl=20 to shorten the wait).

Demo · the claim, running on real mainnet data

The disagreement is the product

1:18 · 1080p · h264/aac · subtitles: VTT · SRT · MP4

One real-time take. The 31 node observations behind a single Chainlink ETH/USD print — decoded from the NewTransmission log at block 20,458,998, mid-cascade on 5 Aug 2024 — become 31 readings, each under its own key, 868 bps apart. The outlier is named by its $creator, the median is drawn and never written, and when the outlier's own lifetime runs out a disputant cannot extend it — only the copy they paid to pin survives. Data: chainlink_round_20458998.json. Run it yourself: demo/selisih.html.
